# 置いた色が広がって馴染む仕組み

塗りの上に筆を置いたとき、色が水を伝って広がり、下の色と馴染む挙動を作っている仕組みと、その効きを変えたいときに触る場所。パラメータの既定値と範囲は [../parameters.md](../parameters.md) が正典。ここに至った試行錯誤は [../memo/2026-07-09-wet-blending-tuning.md](../memo/2026-07-09-wet-blending-tuning.md) と [../memo/2026-07-09-capillary-water.md](../memo/2026-07-09-capillary-water.md)。

土台の流体モデル(Curtis 1997 の速度更新 → 発散緩和 → 移流)は [01-fluid-simulation.md](01-fluid-simulation.md)。

---

## 0. 設計の軸: 水の量がすべての効きを決める

**「水がどれだけあるか」を全ての効きの軸にする**。たっぷり=自由に動いて混ざる/引いてきた=止まって定着、が各機構で一貫していれば、アナログ水彩の直感と一致する。以下の5つはどれもこの軸で効きが変わる。

| 仕組み | 体感 | 場所 |
|---|---|---|
| 水の毛細管拡散 | 置いた水が濡れた紙を伝ってひとりでに広がり、水が引くと止まる | [diffuse.wgsl](../../assets/shaders/diffuse.wgsl) `cap_weight` |
| 混ざりの水依存 | たっぷりなら傾斜がなくても混ざり、乾きかけでは混ざらず縁の形が残る | [diffuse.wgsl](../../assets/shaders/diffuse.wgsl) `wet_weight` |
| しきい値型の吸着 | 水膜がある間は顔料が沈まず、膜が切れてから定着する | [transfer.wgsl](../../assets/shaders/transfer.wgsl) `deposit_weight` |
| 薄い水膜の流れ止め | 乾きかけは流れが止まってから定着する(紙目のざらつきを防ぐ) | [velocity.wgsl](../../assets/shaders/velocity.wgsl) `FLOW_MIN` |
| 筆の含み・溶かし戻し | 置いたままでも色水が流れ出続け、下の色が浮いて混ざる | [splat.wgsl](../../assets/shaders/splat.wgsl) 描画ブランチ、`PaintApp::feed_charge` |

## 1. 水の毛細管拡散(簡易 Richards)

速度場の水の移動手段は「水面勾配 → 加速 → 移流」だけなので、置いた水の山は平らになると止まり、外向きの発散は relax パスが消す。毛細管現象(水自身が濡れた紙を伝って広がる力)がないと、乾きかけの塗りに置いた色は広がらない。

そこで diffuse パスの反復ループで、顔料と同時に**水量そのものを拡散**させる:

```
wflux += cap_weight(w_self, w_neighbor) × perm × (w_neighbor − w_self)   // 濡れセル間のみ
w' = w + min(WATER_DIFFUSE×dt, 0.2) × wflux
cap_weight(a, b) = max(a, b)^WATER_GAMMA
```

- **重みは平均ではなく max^γ**: 毛細管の吸引は受け側が乾いているほど強い。平均にすると「たっぷりの筆 × 乾きかけの下地」の界面で流束が死に、乾きかけに置いても広がらない。max なら濡れ側の水量で流束が立つ
- **水量が全体に下がると max も下がって流束が消える** = 「水が引くと止まる」が同じ式から出る
- 対称流束なので**質量保存**。濡れマスクの境界は Neumann(白紙へのストローク輪郭は広がらない)。ペン線の透水率・アクティブタイルは顔料拡散と同じ経路で効く
- 陽解法の安定条件(1反復の係数 ≤ 0.2)は顔料と同じ。速さは `diffuse_iters` で稼ぐ
- 顔料は §2 の重みで水を後追いするので、水が先行するクロマトグラフィー的な水の輪も出る
- **広がる距離はパラメータではなく物理から出る**: 置く水の量(`brush_water`)× 含みの長さ(`brush_charge`)が多いほど遠くへ広がる

## 2. 混ざりの水依存(顔料拡散の重み)

顔料の拡散流束の重みを `(両セルの水量平均)^DIFFUSE_GAMMA`(γ=4)にしている。w=1.0 で全開・w=0.7 で約1/4・w=0.5 で約1/16。

- 「水がたっぷり=**傾斜がなくても濃度差だけで**自由に混ざる/水が引く=急に混ざらなくなり縁の形が残る」が1本のカーブで出る
- 拡散は濃度差駆動なので、顔料のない水へは差が最大=一番速く広がる
- 水の拡散(γ=2、max)より急なカーブにして、水が先、顔料が後になるようにしている

## 3. しきい値型の吸着と薄い水膜の流れ止め

吸着率は水量に対して**しきい値型**: `mix(2.0, DEPOSIT_WET_FLOOR, smoothstep(0, DEPOSIT_DRY_POINT, w))`。水膜が保たれている間(w ≥ 0.35)は床(0.1)に張り付き、膜が切れると立ち上がる。実物の水彩で沈着が始まるのはウォッシュの流れが止まってから、を表す。

- 水量に比例して滑らかに減るカーブだと、毛細管拡散が水の山を薄く延ばして運ぶ途中(中間水量 0.3〜0.6)で吸着が効き、色が移動の途中で固まる
- 毛細管拡散は移流より運びが遅いので、浮遊時間を長く取る必要がある(床を低くしている理由)

顔料が低水量まで浮遊し続ける副作用として、乾きかけの薄い水が紙目(`paper_amp`)に沿って流れ、浮遊顔料を谷へ寄せ集めてざらつく。低水量では顔料拡散の重み(平均^4)も効かないので、寄った顔料を均す機構がない。そこで velocity.wgsl で `vel ×= smoothstep(0, FLOW_MIN, w)`(FLOW_MIN=0.3)とし、薄い水膜の流れを止める(実物でも薄膜の流量は厚さの3乗で消える=潤滑近似)。**「流れが止まる(w<0.3)→ 定着が仕上がる(w<0.35 から立ち上がり)」の順序**になるよう、FLOW_MIN を DEPOSIT_DRY_POINT よりわずかに下に置く。

## 4. 筆の含み(feed splat)

splat はポインタが動いたときにしか生まれないので、そのままでは「置いたまま=何も起きない」。

- 塗る筆を置いたまま動かないフレームでも、筆の中身の水が残る間は **CPU(`PaintApp::feed_charge` → `BrushFrame::feed`)が毎フレーム feed splat(`Splat.feed=1`)を1つ積む**(筆の水を減らすのは GPU の brush.wgsl)
- feed splat の中身は通常の splat と違う: 水は目標水位への max 補充(積み上がらない。目標は筆の中身の水に比例)、顔料は通常の `CHARGE_PIGMENT`(0.15)倍だけ。広げるのは毛細管拡散の仕事で、流れ出るのは主に水
- 流れ出るぶん筆の中身の水を使い、満タンの筆は `brush_charge` 秒で尽きる。描いて減った筆ほど早く止まる。動いているフレームは通常の注入があるので積まない
- **既知の制約**: ストローク記録(H5)は生ポインタ点だけを記録するので、「置いたまま保持」は再生で再現されない

## 5. 色の溶かし戻しと脱着

新しい色は浮遊層(動ける)、既存の色は沈着層(動けない)にいるので、そのままでは新しい色が上に乗るだけで、既存の色は新しい塗りの方へ広がってこない。既存の色が戻る経路は**再浮遊 → 濃度差拡散**だけ。

- **溶かし戻し**(`paint_pickup`): 塗る筆が触れた沈着顔料を `paint_pickup × coverage × 筆圧 × (1−ω)` の割合で浮遊層へ戻す(リフトの弱い版)。筆の色と下の色が同じ浮遊層で混ざるので境界が濁らず馴染む。feed splat では毎フレーム来るので 0.1 倍に弱めている(そのままだと1秒で筆の下が全部剥がれる)
- **脱着**(`lift_rate`): 新しい水が乗った既存色が、水量に応じて再浮遊する速さ。速めにして既存色がほどけて戻るようにしている
- どちらもステイニング ω で変調されるので、フタロ・キナクリドンのような染みつく顔料はほぼ戻らない(仕様)

## 6. 調整ガイド

| 体感を変えたい | 触る場所 |
|---|---|
| 広がる**距離** | 置く水の量(`brush_water`)・筆の含み(`brush_charge`)。毛細管の速さは `WATER_DIFFUSE` / `WATER_GAMMA` / `diffuse_iters` |
| 下の色との**馴染み** | 下の色を溶かす(`paint_pickup`)・脱着(`lift_rate`) |
| 混ざる**速さ・自由さ** | 拡散率×反復(`pigment_diffuse` / `diffuse_iters`、開発モード → 味付け) |
| たっぷり/乾きかけの**メリハリ** | `DIFFUSE_GAMMA`(顔料)・`WATER_GAMMA`(水) |
| 定着の**タイミング**・乾きかけの**ざらつき** | `DEPOSIT_WET_FLOOR` / `DEPOSIT_DRY_POINT`(transfer.wgsl)・`FLOW_MIN`(velocity.wgsl)。順序を崩さない |
| 置いたまま出る**色の濃さ** | `CHARGE_PIGMENT`(splat.wgsl)、または `brush_pigment` |

- WGSL の定数はホットリロード(H1)で編集すれば再起動なしで効く。一度調整すれば作画中に変えない「シミュの性格」なので、SimParams ではなく定数にしている。スライダーに戻したくなったら parameters.md §11 の定型作業で昇格できる
- **毛細管拡散・水依存 γ・しきい値型の吸着・FLOW_MIN は塗る筆専用ではなく全体の性質**。水筆の水たまり・全面再湿潤・白紙への単ストロークも同じ物理で振る舞う
