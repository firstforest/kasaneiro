# パラメータリファレンス

全シミュレーションパラメータ(`SimParams`、[crates/paint-core/src/sim.rs](../crates/paint-core/src/sim.rs))と顔料個性の意味・既定値・UI 範囲の一覧。**定義の正典はコード側のフィールドコメント**(SimParams)と [crates/pigment/src/lib.rs](../crates/pigment/src/lib.rs)(顔料個性)であり、本書は一覧性のためのリファレンス。プリセットは `assets/presets/*.json`(serde default で足りないフィールドは既定値で埋まる)。

## 1. ブラシ

| パラメータ | 既定値 | UI 範囲 | 意味 |
|---|---|---|---|
| `brush_radius` | 16.0 | 1〜64 | ブラシ半径(テクセル単位) |
| `brush_water` | 0.5 | 0〜2 | 水量: 紙が満タンに濡れた水位 = `brush_water` × `SAT_RATIO`(4.3)。塗る筆は紙をこの水位 × 穂先の濡れ具合まで濡らす。削りが 1 splat あたりに置く水量にも使う |
| `brush_velocity` | 1.0 | 0〜2 | 筆の勢い: 塗る筆の穂先から出た水が持つストローク方向の速さ(× 穂先の濡れ具合の3乗)。紙の水と運動量で混ぜるので、紙の速度 = (速度 × 水 + `brush_velocity` × 穂先の濡れ具合³ × 進行方向 × 出た水) ÷ (水 + 出た水)。吸っているときは与えない |
| `brush_pigment` | 0.11 | 0〜1(開発モード) | 色1回分の顔料量: 満タンの室に標準の1回分(顔料 1)のとき、紙の上で濃さ(浮遊顔料 ÷ 水)が `brush_pigment` ÷ `brush_water` になる単位。通常の濃淡は筆の中身で作るので、通常 UI には出さない |
| `brush_channel` | 0 | 色見本ボタン | 選択中の顔料スロット(0〜3 = パレットの4スロット。§9)。色をつくるの対象(筆へのスポイトの後は拾った中で一番多い色)。塗る色は筆の中身(下記)が決める |
| `tool` | 0 | ツールボタン | 0=描画 / 1=リフト(削り) / 2=消去 / 3=吸い取り(splat.wgsl が分岐) |
| `lift_strength` | 0.3 | 0〜1 | リフト(tool=1)の基準強度。実効値は顔料の ω と紙ハイト(凸部ほど剥がれる)で変調 |
| `lift_blot` | 0.5 | 0〜1 | リフト(tool=1)の吸い取り: 浮かせた後、1 splat で水・浮遊顔料・速度を取り去る割合(coverage×筆圧で変調。吸い取り tool=3 と同じ式)。浮かせるだけだと色は周りへ移るだけなので、その場から色を抜くために押さえて吸う。0 = 浮かせるだけ |
| `paint_pickup` | 0.2 | 0〜1 | 色の溶かし戻し: 塗る筆が触れた沈着顔料を浮遊層へ戻す割合(coverage×筆圧×(1−ω) で変調。リフト tool=1 の弱い版)。筆の色と下の色が同じ浮遊層で混ざり、置いた境界が馴染む。水だけの筆(顔料 0)でなでるときはこれがぼかしの強さになる。feed splat 経由(筆の含み)では毎フレーム適用になるため 0.1 倍に減衰される。0=無効 |
| `brush_exchange` | 0.3 | 0〜1(開発モード) | 穂先と紙の受け渡しの速さ: 1 splat で動く水 = `brush_exchange` × coverage × 筆圧(`pressure_water` で変調)×(穂先の濡れ具合 − 紙の濡れ具合)× 満タン水位。正なら穂先 → 紙(顔料は穂先の濃さ × 筆圧(`pressure_pigment`)で出る)、負なら紙 → 穂先(浮遊顔料は紙の濃さで入る。穂先の渇き(1 − 濡れ具合)を掛ける)。1回なぞる間に筆跡が約 6 回重なるので、0.3 で紙が穂先の濡れ具合の 9 割近くまで濡れる |
| `absorb_rate` | 0.5 | 0〜1 | 吸い取り(tool=3)の強さ: 1 splat で表面の自由水と浮遊顔料を取り除く割合(coverage×筆圧で変調)。浮遊顔料は水に乗っているだけなので水と同率で取れ、ω(染みつき)は関与しない。沈着顔料は紙に付いているので残る(剥がすのはリフト)。速度も同率で減衰=吸った水の運動量ごと持ち去る |
| `brush_hold` | 500 | 0〜5000 px | 筆の腹の大きさ: 満タンの腹だけで乾いた紙をこの長さ塗ると半分になる(既定 500px で、乾いた紙にキャンバス幅の線を1本引くと 6〜7 割まで減る。濡れた所ではほとんど減らない)。容量 = `brush_hold` × `CROSS_RATIO` × `brush_radius` × 満タン水位 ÷ ln2(紙のセルの量)。腹は紙と直接は受け渡さず、穂先へ送る。0 = 減らない筆(紙から吸いもしない) |
| `brush_tip` | 80 | 10〜1000 px | 筆の穂先の大きさ(容量の式は腹と同じ)。穂先が紙と受け渡す。小さいほど吸った色ですぐ満ち、その色を短く運ぶ。80px で吸った色を 100px ほど運ぶ |
| `brush_refill_time` | 0.05 秒 | 0〜2 秒(開発モード) | 腹から穂先へ送る時定数: 腹が穂先より濡れていれば、濡れ具合の差(2室が揃う量)を `1 − exp(−dt/τ)` だけ詰める。顔料は腹の濃さで一緒に動く。一方向(穂先 → 腹へは戻さない)。dt は前回の brush パスからの経過(筆を上げていた間の分は次に塗るフレームでまとめて、上限 2 秒)。0.05 秒で、ふつうの速さ(300px/秒)で描いても穂先が 9 割近くを保つ |

**筆の中身**([crates/paint-core/src/load.rs](../crates/paint-core/src/load.rs) の `BrushLoad`): 塗る筆は穂先と腹の2室で、各室が水 W(1 = その室が満タン)と4スロットの顔料 c(1 = 標準の1回分)を持つ。中身は GPU の筆バッファにあり、穂先と紙が受け渡す(`brush_exchange`)。次に置く色の濃さ = 穂先の Σc ÷ W。中身を作るのはツールバーの色・水・洗う(穂先と腹の両方にかける。洗うは水も顔料も 0 の空の筆にする。空の筆は紙に何も置かず、濡れた所の色水を吸うだけ)で、量は SimParams ではなく load.rs の定数で決まる:

| 定数 | 値 | 意味 |
|---|---|---|
| `TAKE_DOSE` | 1.0 | 色スウォッチを押した瞬間に足す顔料。水は満タンにする |
| `TAKE_RATE` | 1.0 /秒 | 色スウォッチを押し続けている間に足す顔料 |
| `PIGMENT_MAX` | 4.0 | 筆が含める顔料の合計の上限(比率を保って頭打ち) |
| `DIP_KEEP` | 0.5 | 水スウォッチを押した瞬間に残る顔料の割合(水は満タンにする) |
| `DIP_TAU` | 0.25 秒 | 水を押し続けている間に顔料が抜ける時定数 |
| `CLEAN_EPS` | 0.02 | 顔料の合計がこれを下回ったら 0 に切る(いちばん濃い筆でも約 1.2 秒で透明) |
| `FEED_MIN_WATER` | 0.02 | 穂先と腹の水がどちらもこれを下回ったら、置いたまま動かない筆の splat を出すのをやめる(出しても受け渡しはほぼ無い)。濃さの表示も水がこれ以下なら 0 |

自動補充(左パネルの「筆を下ろすたびに含み直す」、既定 off)は、最後に色・水・洗うで作った中身へ筆を下ろすたびに戻す。off なら前のストロークの残りから続き、乾きかけた筆で濡れた色を吸える。

「置いた色が外へ広がる」挙動はパラメータではなく**水の毛細管拡散**([note/05](note/05-wet-spreading.md)、§4 の定数 `WATER_DIFFUSE`/`WATER_GAMMA`)が担う。広がる距離は紙を濡らす水位(`brush_water`)と、置いたままの筆が紙と釣り合うまで流し続ける水で決まる。

## 2. 筆圧(M1.5)

実効値 = 基準値 × `mix(1, 筆圧^γ, 効き)`。マウス(筆圧 1.0)では常に基準値のまま。

| パラメータ | 既定値 | UI 範囲 | 意味 |
|---|---|---|---|
| `pressure_radius` | 1.0 | 0〜1 | 筆圧→半径の効き(0=筆圧無効 / 1=完全比例)。既定は完全比例で、軽いタッチほど細部を塗れる細さになる(実効半径の下限 0.5px) |
| `pressure_water` | 0.0 | 0〜1 | 筆圧→水量の効き。既定 0 = 筆圧で濃さを変えない(水が減ると紙が濡れきらず線が薄くなる) |
| `pressure_pigment` | 0.0 | 0〜1 | 筆圧→顔料量の効き。既定 0 = 筆圧で濃さを変えない |
| `pressure_gamma` | 1.0 | 0.25〜4 | 応答カーブ γ(筆圧^γ)。1=線形、>1 で軽いタッチがより細く弱くなる |

|---|---|---|---|
| `dt` | 0.5 | 0.05〜1 | シミュレーションの時間刻み |
| `accel` | 1.0 | 0〜4 | 移流強度: 水面勾配 → 加速度の係数。水面 = 水深 + `paper_amp`×紙ハイト |
| `damping` | 0.02 | 0〜0.5 | 速度減衰(粘性の代用。1ステップあたりの減衰率)。既定は筆が与えた流れが約 0.6 秒で半分になる値 |
| `xi` | 0.1 | 0〜0.5 | 発散緩和の係数 ξ(δ = −ξ·div。Curtis 1997 の既定は 0.1) |
| `relax_iters` | 16 | 1〜50 | 発散緩和の反復回数/ステップ(安全弁の上限 64) |
| `vel_max` | 1.0 | 0.1〜2 | 速度上限(セル/ステップ)。CFL 的制約として 1.0 以下を推奨 |
| `wet_expand` | 0.2 | 0〜0.5 | にじみ拡張率: 乾いたセルのマスクが濡れた隣の水量に比例して育つ速さ(0.5 超で濡れに昇格)。0 = 筆が通った領域に固定。実効の速さは下の `wick_bare` / `wick_ref` で、そのセルの沈着顔料の量によって変わる。既定では乾いた色の上に置いた色が 30〜40px 先まで遠いほど薄く馴染む。0.05 では前線が数 px で止まり、その内側で色が均されて前線に段が残る |
| `wick_bare` | 0.0 | 0〜1 | 白い紙への染み込み: 沈着顔料のない乾いたセルで `wet_expand` に掛ける倍率。0 = 白い紙へは濡れ前線が進まず、色のある所へだけ染みる / 1 = 顔料の有無で差をつけない |
| `wick_ref` | 0.05 | 0.005〜0.5(log) | 染み込みが最大になる沈着量(4ch の和)。乾いたセルの沈着量がこれに達すると `wet_expand` そのままの速さで、少ないと `wick_bare` との間を smoothstep で補間する。0.05 ≈ 被覆率 5% の薄塗り |
| `advect_sharp` | 1.0 | 0〜1 | 移流の MacCormack 補正の割合。0 = セミラグランジアン(バイリニア補間で毎ステップぼける)/ 1 = 往復の誤差を半分戻し、前進サンプルの4タップの範囲に収める |

## 4. 顔料の輸送(diffuse / transfer)

| パラメータ | 既定値 | UI 範囲 | 意味 |
|---|---|---|---|
| `pigment_diffuse` | 0.1 | 0〜1 | 顔料拡散率(1反復あたり。安定条件のため WGSL 側で 0.2 に制限)。既定 0.1×dt0.5=実効 0.05。筆の流れが作った跡を均しきらず、置いた境目は馴染む値(0.2 だと流れの跡が消え、0.05 以下だと境目の馴染みが狭い)。0.4 以上で上限に張り付く。水の毛細管拡散(WATER_DIFFUSE)には影響しない |
| `diffuse_iters` | 12 | 0〜32 | 拡散の反復回数/ステップ。実効的なにじみ速度 = 拡散率 × 反復回数。速いにじみはこちらで稼ぐ |
| `deposit_rate` | 0.05 | 0〜0.5 | 吸着率: 浮遊顔料が紙へ沈着する速さ(水が少ないほど強い)。顔料の ρ と粒状ゲートで変調 |
| `lift_rate` | 0.1 | 0〜0.5 | 脱着率: 沈着顔料が水に浮き上がる速さ(水が多いほど強い)。顔料の (1−ω) で変調。毛細管モデル(note/05)では既存色が新しい塗りへ戻る経路が再浮遊→拡散だけなので速めにしている |
| `evap_rate` | 0.0003 | 0〜0.05(log) | 蒸発率: 濡れ領域の水が 1 ステップに減る量。既定は水量 0.5 の塗りが約1分保つ値。シミュは 1/60 秒の固定刻みで進む(速度倍率 1 で 1刻み 1ステップ)ので、モニタの Hz に依らない |

transfer.wgsl の実効式(per-channel、M3):

```
吸着 = deposit_rate × ρ × dt × deposit_weight(水量) × 粒状ゲート(paper_gran×γ)
       deposit_weight(w) = mix(2.0, DEPOSIT_WET_FLOOR, smoothstep(0, DEPOSIT_DRY_POINT, w))
脱着 = lift_rate × dt × 水量 × (1−ω)
```

diffuse.wgsl の顔料の流束(per-channel、隣 n から自セルへ):

```
流束 = (水量平均)^DIFFUSE_GAMMA × 透水率 × (c_n × (1+d) − c × (1−d))
       d = clamp(½ × (φ_n − φ), ±DRIFT_MAX)
       φ = paper_drift × γ × 紙ハイト + mix_mottle × (斑の場 g, b を顔料ごとの向きで組み合わせた値)
係数 = min(pigment_diffuse × dt × μ, 0.2)
```

濡れている間、顔料は c ∝ exp(−φ) の分布へ向かう(φ が小さい所に溜まる)。乾くと重みが消えて止まる。

### 調整済みの WGSL 定数(SimParams ではない)

作画中に変えない「シミュの性格」は SimParams ではなく各シェーダーの `const` に置く(理由と調整ガイドは [note/05](note/05-wet-spreading.md) §6)。再調整はホットリロード(H1)でシェーダーを直接編集する(SimParams のレイアウトが変わらないので再起動不要):

| 定数 | 値 | 場所 | 意味 |
|---|---|---|---|
| `FLOW_MIN` | 0.3 | [velocity.wgsl](../assets/shaders/velocity.wgsl) | 薄い水膜の流れ止め(潤滑近似): この水量以下で速度が消えはじめる。乾きかけの紙目駆動の流れが浮遊顔料を谷へ寄せてざらつくのを防ぐ。吸着の立ち上がり(DEPOSIT_DRY_POINT)よりわずかに下 |
| `WATER_DIFFUSE` | 0.15 | [diffuse.wgsl](../assets/shaders/diffuse.wgsl) | 水の毛細管拡散の速さ(per-iter 上限 0.2、×diffuse_iters)。置いた水が濡れた紙を伝って広がる(note/05) |
| `WATER_GAMMA` | 2.0 | [diffuse.wgsl](../assets/shaders/diffuse.wgsl) | 水の毛細管の水依存カーブ: 流束の重み = max(両セル水量)^γ。max なのは乾きかけへ吸い込まれる向きを殺さないため |
| `DIFFUSE_GAMMA` | 4.0 | [diffuse.wgsl](../assets/shaders/diffuse.wgsl) | 顔料の混ざりの水依存 γ: 拡散流束の重み = (水量平均)^γ。水たっぷり=自由に混ざる/引くと止まる |
| `FOOTPRINT_RATIO` | 1.25 | [sim.rs](../crates/paint-core/src/sim.rs)(プレリュードで WGSL へ) | 塗る筆の 1 splat の触れ方 touch = clamp(r − d + 0.5, 0, 1) × min(1/√(1−(u/r)²), `CHORD_MAX`) を円で積分した面積 ÷ πr²(u = 進行方向と直交する中心線からの距離)。CPU の「乾いた紙での減りの上限」の予測に使う |
| `CROSS_RATIO` | 2.0 | [sim.rs](../crates/paint-core/src/sim.rs)(プレリュードで WGSL へ) | 1回なぞって濡れる帯の幅 ÷ r(塗る筆は円の内側が一様に触れ、弦の補正で幅のどこでも同じだけ受け渡すので 2r)。穂先・腹の容量の式に使う |
| `CHORD_MAX` | 3.0 | [sim.rs](../crates/paint-core/src/sim.rs)(プレリュードで WGSL へ) | 弦の補正の上限。筆跡の縁のセルほど 1 回なぞる間に触れる splat が少ない分(弦 ∝ √(1−(u/r)²))を 1 splat あたりに掛け戻す倍率が、縁で発散しないよう頭打ちにする |
| `SAT_RATIO` | 4.3 | [sim.rs](../crates/paint-core/src/sim.rs)(プレリュードで WGSL へ) | 紙が満タンに濡れた水位 = `brush_water` × これ。満タンの筆で乾いた紙を1回なぞり、筆跡の幅の中で均された後の水位の計測値([memo](memo/2026-11-01-brush-exchange.md) §6) |
| `SPLAT_SPACING` | 0.25 | [sim.rs](../crates/paint-core/src/sim.rs) | splat の間隔 = 実効半径 × これ(下限 0.25px。`SimParams::splat_spacing`)。ポインタ点の間の1区間でも、各地点の補間した筆圧の半径で間隔を決める(筆圧が大きく変わる払いの区間で、太い所に細い筆用の間隔で splat が詰まらない)。ライブ描画・記録の再生・ラスタ線画の履歴のストローク補間が使う。下限を 1px にすると細い線ほど1セルをなぞる回数が減り、紙が穂先の濡れ具合まで濡れきらず線だけ薄くなる |
| `DEPOSIT_WET_FLOOR` | 0.1 | [transfer.wgsl](../assets/shaders/transfer.wgsl) | 水膜がある間(w ≥ DRY_POINT)の吸着倍率。0 にすると濡れている間は全く沈まない |
| `DEPOSIT_DRY_POINT` | 0.35 | [transfer.wgsl](../assets/shaders/transfer.wgsl) | 吸着が立ち上がる水量しきい値(=水膜が切れる点)。上げるほど早く沈み始め、下げるほど流れている間は浮遊し続ける |
| `DRIFT_MAX` | 0.25 | [diffuse.wgsl](../assets/shaders/diffuse.wgsl) | 顔料の寄り(φ の差)による流束の偏り d の上限。陽解法の安定条件(4 近傍 × 0.2 × (1+d) ≦ 1)から決まる |
| `MOTTLE_MIX` | 0°/90°/45°/135° | [diffuse.wgsl](../assets/shaders/diffuse.wgsl) | 混ざりムラの場2枚 (g, b) を顔料スロットごとに組み合わせる向き。どの2顔料も向きが違うので混ぜた色の比率が揺れる |

## 5. 紙([crates/paint-core/src/paper.rs](../crates/paint-core/src/paper.rs))

紙は起動時に CPU 生成する静的な rgba32float テクスチャ。r = 紙ハイト(値ノイズ4成分: 低周波の沈殿ムラ+中周波の紙目+微細なざらつき+横方向の繊維ストリーク)、g, b = 混ざりムラの場2枚(グラディエントノイズ3オクターブ、周期 48 / 21 / 9px、オクターブごとに座標を回して格子の向きを散らす)。

濡れている間の顔料の寄り(`paper_drift` / `mix_mottle`、diffuse.wgsl、式は §4)は既定で効かせている。それ以外の紙の質感(`paper_amp` / `paper_gran` / `paper_wet`)は既定 0 で、スライダー(開発モードの「紙・エッジ」)で値を上げれば効く。線画の鉛筆粒状感(`pencil_gran`、§10)と、リフトの紙凸部変調(顔料 γ 依存、splat.wgsl)は紙ハイトをそのまま使う。

| パラメータ | 既定値 | UI 範囲 | 意味 |
|---|---|---|---|
| `paper_amp` | 0.0 | 0〜1 | 紙ハイトの振幅: 水面勾配に足す凹凸の強さ(水が谷へ流れる → ストリーク) |

## 9. 顔料個性 ρ/ω/γ/μ(M3、[crates/pigment/src/lib.rs](../crates/pigment/src/lib.rs))

SimParams とは別に、顔料ごとの物性4値を uniform(binding 9、vec4 の xyzw)で渡す。**M5 でランタイム編集可能**([`Palette`]、パレットパネルで色・ρ/ω/γ/μ を編集 → `set_palette` が physics/latents バッファへ即時反映)。物性は湿シミュ専用=全レイヤー共通で、編集は過去の乾燥レイヤーに遡らない。色(latent)は「乾かす」時にレイヤーへ記録するため乾燥済みは変色しない(M5c)。**per-顔料の密度 ρ(`density`、沈着の速さ)と、表示の被覆率カーブ `pigment_density`(§8)は別概念**。

| 物性 | 範囲(UI) | 意味 |
|---|---|---|
| 密度 ρ (`density`) | 0.1〜2.0 | 沈着(吸着)の速さ。重い顔料ほど早く沈む(transfer の吸着を倍率変調) |
| ステイニング ω (`staining`) | 0〜1 | 剥がれにくさ。高いほど脱着・リフトが (1−ω) で抑えられ紙に色が残る(ステイン床) |
| 粒状感 γ (`granulation`) | 0〜1 | 紙ハイトへの反応。高いほど凹部(谷)に沈着し凸部で剥がれる = 粒状化 |
| 粒の細かさ μ (`mobility`) | 0.1〜2.0 | 顔料拡散の倍率(diffuse の per-channel 係数 = min(`pigment_diffuse`×dt×μ, 0.2))。細かい顔料(μ>1)は水に乗って遠くまで伸び、粗い粒(μ<1)はその場に残る。**μ の差が分離色の主役**: 2顔料を筆に取って置く(色スウォッチを続けて押す、§1)と細かい方だけ縁へ走って2色に分かれる。JSON に μ が無ければ serde default で 1.0 |

GPU へ渡す前に `physics_uniform()` が ρ・μ を 0 以上、ω・γ を 0〜1 に収める(NaN は 0。手で書き換えた JSON 対策で、UI 範囲の値は変わらない)。diffuse の μ 由来の係数も WGSL 側で [0, 0.2] に収める。

既定パレット(mixbox 推奨顔料色、対比を付けた代表値。UI で編集可):

| スロット | 顔料 | sRGB | ρ | ω | γ | μ | 性格 |
|---|---|---|---|---|---|---|---|
| 0 | ハンザイエロー | 252,211,0 | 1.0 | 0.5 | 0.1 | 1.0 | 半透明・中ステイニング・ほぼ非粒状 |
| 1 | フタロブルー | 13,27,68 | 0.8 | 0.9 | 0.05 | 1.2 | 微細粒子。強ステイニング(剥がれない)・非粒状・軽い・よく伸びる |
| 2 | キナクリドンマゼンタ | 128,2,46 | 0.9 | 0.85 | 0.05 | 1.1 | 透明・強ステイニング・非粒状 |
| 3 | バーントシェンナ | 123,72,0 | 1.3 | 0.2 | 0.8 | 0.3 | アース系。重く早く沈着・低ステイニング(よく剥がれる)・強粒状(紙目に溜まる)・粗い粒でその場に残る(フタロと混ぜると分離色) |

この4色は色単体ライブラリ(`assets/pigments/*.json`、M5f)にも同じ値で同梱してある(1色=1ファイル、`Pigment` の serde そのまま。スキーマは本節の4値+名前+sRGB。μ は `#[serde(default)]`=1.0)。同梱パレット [default.json](../assets/palettes/default.json) もこの4色で、コードの `default_palette()` と同値であることをテストで検査している。ライブラリにはさらに定番の水彩絵具18色(カドミウム系・コバルト系・アース系・フタログリーン・ペインズグレー等)を、実物の性質(カドミウム=不透明で重い/キナクリドン・フタロ・ディオキサジン=透明で強ステイン・微細/コバルト・アース=粒状で沈む・粗い)を ρ/ω/γ/μ に写した値で同梱している。色はスロットの4色と同様 mixbox 推奨顔料色(該当があるもの)を使う。

## 10. 線画(M4.5、linesplat.wgsl / display.wgsl)

鉛筆・ペン・ハイライトのラスタツール。流体シミュを通らず、`linesplat.wgsl` が対象の線画テクスチャ(r32float、鉛筆用/ペン用/ハイライト用の各1枚)へインク濃度(ハイライトは不透明度)を直接蓄積する。半径・筆圧の効きは「1. ブラシ」「2. 筆圧」の値を共用。

| `line_eraser` | 0 | チェックボックス | ラスタ消しゴム: 0=描画(蓄積)/ 1=減算 |

## 10.5 アクティブタイル(M6)

| パラメータ | 既定 | UI 範囲 | 意味 |
|---|---|---|---|
| `active_tiles` | 1 | チェックボックス | **アクティブタイル最適化(M6)**。0=全面計算 / 1=濡れタイル+ブラシ近傍のタイルだけシミュレーションを走らせる。シミュコストを「紙の広さ」比例から「濡れ面積」比例へ。0 で全面計算(A/B・不具合時の退避)。診断表示(H4)の「アクティブタイル」モードで計算中の範囲を目視できる |

## 11. パラメータを追加するときの手順(H2 の定型作業)

1. [crates/paint-core/src/sim.rs](../crates/paint-core/src/sim.rs) の `SimParams` にフィールド1行 + `Default` に既定値(16 バイト整列の扱いは下記)
2. [src/app/ui/](../src/app/ui/) の該当パネルにスライダー1行
3. [assets/shaders/common.wgsl](../assets/shaders/common.wgsl) の `struct SimParams` に1行(Rust 側と同レイアウト。名前・順序・型の不一致は [tests/sim_params_layout.rs](../tests/sim_params_layout.rs) が検出する)

**現在のレイアウト**: `SimParams` は 64 フィールド(全て f32 / u32 の 4 バイト)= 256 バイト(16×16)、パディングなし。次に足すときは末尾に `_pad: [f32; 3]` を置く。`Splat` は 32 バイト(`pos`・`vel`・`pressure`・`feed`・`scale`・`_pad`)。筆の中身 `BrushState` は 64 バイト(穂先の `tip_water`・`_pad`×3・`tip_pigment: [f32; 4]`、腹の `belly_water`・`_pad`×3・`belly_pigment: [f32; 4]`)。

**16 バイト整列の保ち方**: uniform buffer は Rust の構造体を bytemuck で生バイトのまま渡すので、全体サイズを 16 の倍数に保つ(`params_size_aligned` テスト)。次にフィールドを足すとき 16 の倍数から外れるなら、Rust 側の末尾に `#[serde(skip)]` のパディング(例: 1個足すなら `_pad: [f32; 3]`)を置き、以降はそのパディングを1つずつ実フィールドへ置き換えていく。パディングは WGSL 側の struct には書かない([tests/sim_params_layout.rs](../tests/sim_params_layout.rs) は直列化されるフィールドの名前・順序・型を common.wgsl と突き合わせ、直列化されない末尾 16 バイト未満だけをパディングとして許す)。

**プリセットとの関係**: `#[serde(default)]` なので、フィールドを足しても既存のプリセット JSON は読める(無いフィールドは既定値)。JSON に残った削除済みフィールドは無視される。
